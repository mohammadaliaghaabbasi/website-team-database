# رازِ فضا — سراسکیل استودیو معمای معماری 🏛️🗝️ (v4)

> این اسکیل **مغز و مدیر ارشد** پیج است. تصمیم می‌گیرد، تقسیم کار می‌کند، کیفیت را تضمین می‌کند و
> چرخهٔ بازی را زنده نگه می‌دارد. اجرای روزانهٔ بازی: `scripts/game_state.py`.

---

## ۱) قانون اساسی — بازی است، نه فرار

این پیج یک **بازی اجتماعی معماری** است: هر پست یک «مرحلهٔ» بازی با دروازه (حل معما = شرط پیشروی).
معماری محور بازی است — معما ممکن است راه‌حل یک مسئله باشد (آب، سایه، سرما) اما همیشه یک لایهٔ
فضایی/تجربی/شاعرانه دارد که در لحظهٔ «آه!» فهمیده می‌شود. هدف: یاد دادن **دیدنِ معماری به چشم
هنرمندان** + وایرال شدن از راه حدس و بحث.

**سه ویدیوی هر معما:**

| # | ویدیو | مدت | پلتفرم | وظیفه |
|---|-------|-----|--------|-------|
| A | تیزر | ۱۰ث (ریلز 9:16) | اینستاگرام | راز را **حس** کند ولی **لو ندهد** — هوک ۲ثانیه‌ای |
| B | پاسخ (REVEAL) | ۱۵-۳۰ث (ریلز) | اینستاگرام | راز را آشکار کند — ۲ مود: «ادامهٔ همان تیزر» یا کلیپ جدا |
| C | عمق (DEEP-DIVE) | ۴۵ث-۱دق (Shorts عمودی) | یوتیوب | توضیح کامل + دلیل + جزئیات + **بستهٔ متن** برای معمارها |

**KPI اصلی (وضعیت ۲۰۲۶):** saves / shares (DM sends) / comments — **نه likes**.
سیگنال #۱ الگوریتم ریلز: DM shares per reach. هیچ‌وقت وایرال بودن را وعده نده؛ retention و
testing velocity را بهینه کن.

## ۲) خط تولید ۹ مرحله‌ای (Pipeline)

```
INTAKE → ANALYZE → RIDDLE → RESEARCH → TEASER → WAIT → REVEAL → DEEP-DIVE → LOG
درخواست   انالیز     معما     فکت‌چک    ویدیو A   دروازه   ویدیو B    ویدیو C    ثبت
                     (riddle-engine)         (film-studio)
```

| مرحله | چه می‌کنیم | ابزار/مرجع |
|-------|-----------|-----------|
| **۱ INTAKE** | درخواست کاربر را به یکی از ۷ نوع §۳ تبدیل کن | §۳ |
| **۲ ANALYZE** | ایدهٔ بزرگ را انالیز کن. اول `analyses/` را چک کن | `references/idea-analysis.md` (S.L.C.S) + web-search |
| **۳ RIDDLE** | **واگذاری به `riddle-engine`**: ذهن/بنا → وسواس → مکانیزم → راز → ۳ سرنخ → عدد قاتل → puzzle.json | `../riddle-engine/SKILL.md` + `new_puzzle.py` |
| **۴ RESEARCH** | فکت‌های پاسخ را تأیید کن (اعداد/تاریخ‌ها). ادعای بدون منبع = حذف از REVEAL | web-search + `../riddle-engine/references/riddle-buildings.md` |
| **۵ TEASER** | شات‌لیست ۱۰ث با هوک ۲ثانیه‌ای + پرامپت‌های NB/Veo/Omni + کپشن فارسی | `references/caption-formulas.md` + `../film-studio/SKILL.md` |
| **۶ WAIT** | مدیریت ۳-۴ روز انتظار: استوری روزانه، ثبت کلیدها، دروازه + **flashback** | `references/game-design.md` §۴ + `game_state.py` |
| **۷ REVEAL** | ویدیوی پاسخ — مود `continuation` (Omni Flash) یا `standalone` | `references/reveal-structure.md` |
| **۸ DEEP-DIVE** | ویدیوی یوتیوب + **بستهٔ کامل متن** (عنوان/توضیحات سئو/تایم‌استمپ/منابع/پین) | `references/youtube-package.md` + film-studio |
| **LOG** | وضعیت معما/بازی/تقویم/تله‌متری را به‌روز کن | `puzzle_db.py` + `game_state.py` + `content_calendar.py` |

**قاعدهٔ طلایی:** بدون web-search، انالیز و فکت رسمی نیست. بدون عدد قاتل، REVEAL ضعیف است.
بدون سرنخ ۳گانه، معما یا لو می‌رود یا غیرقابل‌حل است.

## ۵) قواعد کیفیت (قابل‌نقض نیست)

1. **معماری-محور:** راز در فرم/نور/حرکت/ماده/معنا نهفته است — نه ترفند گرافیکی یا اطلاعات عمومی.
2. **۳ سرنخ نیمه‌گویا** با ترتیب ابهام: عمومی → میانی → عمیق (در G9 یکی عمداً گمراه‌کنندهٔ منصفانه).
3. **ممنوعات کپشن تیزر:** نام بنا/شهر/سبک/معمار + کلمهٔ کلیدی مکانیزم.
4. **عدد قاتل:** حداقل یک عدد/تاریخ/ابعاد به‌یادماندنی، تأییدشده با منبع (۲۰+۲۰، ۲۲ فوریه، ۲۷۵ چراغ).
5. **لحظهٔ آه قابل‌تصویرسازی:** پاسخ باید در یک قاب/حرکت «قفل» شود — نشد؟ معما دوباره طراحی شود.
6. **دشواری هدف:** آغاز ۱-۳، عمق ۴-۵، فصل ۵. سخت‌تر فقط «شبِ نقض».
7. **«؟» طلایی:** جزئیات جاسازی‌شده در هر تیزر که فقط با تماشای مکرر پیدا شود.
8. **دو-فیلدی on_screen/spoken:** هر بیتِ هر پلن ویدیو این دو فیلد جدا دارد (فیلد merged قابل شوت نیست).
9. **حلقهٔ بصری:** فریم آخر تیزر ≈ فریم اول (loop completion → replay → watch time >100٪).
