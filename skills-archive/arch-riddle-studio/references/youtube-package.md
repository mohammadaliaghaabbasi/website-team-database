# 📺 بستهٔ کامل متن یوتیوب (YouTube Package)

> خواستهٔ مالک: «آخر هم یک ویدیوی یک‌دقیقه‌ای برای یوتیوب می‌سازیم که راز کامل توضیح داده شده و
> دلیل و جزئیاتش هم در یوتیوب با دیتیل می‌ذاریم که معمارها بتونند ایده بگیرند — **از کپشن و
> توضیحات متنی یوتیوب هم استفاده کنیم و راهنمایی کنیم.**»
> یعنی توضیحات یوتیوب = **درس‌نامهٔ طراحی** است، نه سئوی ساده. این فایل قالب استاندارد آن است.

---

## ۱) اجزای بستهٔ انتشار یوتیوب (۶ قطعه)

| # | قطعه | استاندارد |
|---|------|-----------|
| ۱ | **عنوان** | ≤ ۶۰ کاراکتر؛ فرمول: `معمای معماری N — [قلاب] | [ذهن/بنا]` |
| ۲ | **کاور (thumbnail)** | قاب «لحظهٔ قفل» + عدد/نماد راز + برچسب «؟» طلایی |
| ۳ | **توضیحات (Description)** | قالب §۲ پایین — ۵ بلوک اجباری |
| ۴ | **پین‌کامنت** | سؤال تعاملی + لینک اینستاگرام + جوین جامعهٔ بازی |
| ۵ | **کارت/پایان‌صفحه** | لینک معمای قبلی + لینک اینستاگرام |
| ۶ | **تگ‌ها** | معماری/معماری ایران/معما/انالیز معماری + نام بنا |

## ۲) قالب توضیحات (Description) — کپی-آماده

```markdown
[۱-۲ جمله قلاب: همان قلاب تیزر اینستاگرام، حالا بی‌پرده]

در این ویدیو [نام بنا/ذهن] را باز می‌کنیم: [۱ جمله از راز — پاسخ کامل، اسپویل آزاد است اینجا].

⏱ زمان‌ها:
0:00 معما
0:08 مسئلهٔ پشت طراحی
0:20 مکانیزم — چطور کار می‌کند
0:40 درس طراحی برای معمارها
0:50 جملهٔ پایانی

📐 درس طراحی این قسمت (برای معماران و دانشجویان):
• [بولت ۱: ترجمهٔ عملی مکانیزم به پروژهٔ امروز — مثلاً «بازتاب می‌تواند نصف‌ساز فضا باشد؛
   در پروژه‌های کوچک، سطح آبی/شیشه‌ای را عنصر کامل‌کننده ببینید نه تزیین»]
• [بولت ۲: ابعاد/نسبت کلیدی که باید به‌خاطر سپرد]
• [بولت ۳: یک خطای رایج که این ایده رد می‌کند]

📚 منابع و فکت‌ها:
۱. [FACT ۱ + منبع]
۲. [FACT ۲ + منبع]
۳. [FACT ۳ + منبع]

❓ سؤالات پرتکرار:
س: آیا می‌شد همین کار را بدون [مکانیزم] کرد؟
ج: [۲ جمله پاسخ — این بلوک بحث کامنت یوتیوب را می‌سازد]

🎯 بازی «رازِ فضا» را از دست نده: مرحلهٔ بعد همین حالا در اینستاگرام قفل است
→ [لینک پیج] (حدس بزن تا دروازه باز شود؛ جواب در یوتیوب می‌آید.)

#معماری #معمای_معماری #[تگ بنا/ذهن] #archpuzzle
```

**قواعد توضیحات (v4 — سئو):**
- **کلیدواژهٔ اصلی در جملهٔ اول** (فقط ۲-۳ خط اول قبل از «show more» دیده می‌شود) — مثلاً
  «Abu Simbel architecture mystery» یا «معمای معماری شیخ لطف‌الله» + خلاصهٔ وعده + open loop.
- «One-Sentence Takeaway» (۱۵-۲۰ کلمه) = خط اول — داغ‌ترین جملهٔ محتوا زنده بماند (Spiciest Take Rule).
- تایم‌استمپ‌ها حداقل ۳ تا صعودی.
- «درس طراحی» = قلب بسته؛ ۳ بولت عملی (این همان «راهنمایی معمارها» است).
- هر FACT باید در RESEARCH فکت‌چک شده باشد (web-search) — منبع ذکر شود.
- FAQ از کامنت‌های واقعی اینستاگرام روزهای انتظار برمی‌آید — بهترین FAQها را از حدس‌های نزدیک بردار.
- CTA برعکس‌جهت: یوتیوب → اینستاگرام («مرحلهٔ بعد قفل است») — چرخش دو-پلتفرمی.
- Bridging: تیزر اینستا → Short ۲۲-۳۰ث (زیر آستانهٔ ۱۵ث نماند) → پین‌کامنت لینک REVEAL →
  ویدیوی طولانی در پلی‌لیست فصل — «friction-free loop».

## ۳) عنوان — ۵ فرمول + قواعد CTR ۲۰۲۶

> ساختار داده‌محور: `کلیدواژهٔ اصلی + Curiosity Gap/فایده + Modifier` | کلیدواژه در ۳-۵ کلمهٔ اول |
> طول ۵۵-۶۰ کاراکتر | فقط یک وعدهٔ صادقانه | عدد + براکت | متن ≤۴ کلمه روی تامبنیل (+~۳۰٪ CTR).
> «Start with the result + emotional hook» — نتیجه/معما اول، نه مقدمه. ۳ گزینه بده، A/B بگذار.

| فرمول | نمونه |
|-------|-------|
| متناقض‌نما | «معماری که فقط از یک نقطه صادق است | ذهنِ اشر» |
| عدد قاتل | «۲۰ ستون + ۲۰ چی؟ راز چهل‌ستون اصفهان» |
| سؤال مکانیزم | «این برج بدون برق چطور خنک می‌کند؟ | بادگیر یزد» |
| درس‌محور | «نصفِ معماری را آب می‌سازد — درس طراحی از صفویان» |
| شخصیت ذهن | «اگر تارکوفسکی راهرو می‌ساخت | معمای معماری ۵» |

- اول «معماری» یا «معمای معماری» بیاید (برند + سئو فارسی).
- «|» ذهن/بنا را جدا کند — برند دوگانهٔ پیج: معماری × هنر.

## ۴) کاور (Thumbnail)

- قاب «لحظهٔ قفل» (همان کی‌فریم مهم‌تر از reveal_plan) — نه قاب تیزر (اسپویل ظریف مجاز در یوتیوب: یوتیوب=کتابخانهٔ رازها).
- عدد/نماد راز بزرگ در گوشه: «۲۰+۲۰» / «۲۲ فوریه» / «۹۰ سانت».
- سبک بصری پیج: [STYLE BLOCK از teaser_plan] — قاب ثابت برای شناسایی سریع.
- متن روی کاور ≤ ۴ کلمه.

## ۵) پین‌کامنت استاندارد

```
[سؤال تعاملی از FAQ مثلاً: «به نظرتون اگه حوض خشک می‌شد، این بنا هنوز 'چهل' بود؟»]
بهترین حدس‌های اینستاگرام این بود: [۲-۳ نمونه با متن کوتاه]
مرحلهٔ بعد بازی: [لینک اینستاگرام] 🗝️
```

## ۶) تقویم/پلی‌لیست

- هر فصل = یک پلی‌لیست: «فصل ۱: آب — تمام رازها».
- DEEP-DIVE هم‌روز با REVEAL اینستاگرام (۱۸:۳۰) منتشر شود.
- بعد از فصل: ویدیوی «جامِ فصل» (جمع‌بندی ۵-۷دقیقه‌ای افقی — تنها ویدیوی غیر-Short مجاز).

## ۷) چک‌لیست انتشار یوتیوب

- [ ] عنوان ≤ ۶۰ کاراکتر با فرمول ۵گانه؟
- [ ] کاور = قاب لحظهٔ قفل + عدد قاتل؟
- [ ] توضیحات: ۵ بلوک (قلاب/تایم‌استمپ/درس طراحی/منابع/FAQ)؟
- [ ] ۳ بولت «درس طراحی» عملی است؟
- [ ] همهٔ FACTها منبع دارند؟
- [ ] FAQ از حدس‌های واقعی اینستاگرام آمد؟
- [ ] CTA معکوس به اینستاگرام + لینک؟

- [ ] پلی‌لیست فصل درست است؟
