# اسکیل دامنهٔ مشتریان، CRM و بازاریابی — چاپ بهنام
## نقش
قانون‌گذار دایرکتوری مشتریان، پیگیری‌های پیشنهادی، برچسب‌ها، بلک‌لیست و پیام‌های بازاریابی.
## قوانین تخصصی
- قواعد پیگیری: بدهکار ≥۳۰ روز بدون تماس → «پیگیری تسویه»؛ ≥۶۰ روز بدون سفارش → «بازگشت مشتری»؛ بدون سفارش → «معرفی خدمات».
- مشتری بدون سفارش: دکمهٔ واتساپ = لینک مستقیم wa.me (۰۹→۹۸)؛ دکمهٔ بی‌اثر ممنوع.
- برچسب‌ها/سقف اعتبار/بلک‌لیست/همکار در PUT /api/customers ذخیره می‌شوند (canViewCustomers) — تغییرها لاگ می‌خواهند.
- پیامک‌ها فقط با قالب‌های «متن‌های پیش‌فرض» و درگاه تنظیم‌شده؛ موجودی پنل پیامک نمایشی است مگر API واقعی وصل باشد.
- پیشنهادهای ویژه (specialOffers) فقط با شرط/مهلت صادقانه؛ کپی کد با یک کلیک.
- نظرات صفحهٔ اصلی فقط واقعی/تأییدشده؛ ساختگی با برچسب «واقعی» ممنوع (اعتمادشکن).
