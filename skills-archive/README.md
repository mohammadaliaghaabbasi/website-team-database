- **فهرست کامل با توضیح:** [`docs/SKILLS-INDEX.md`](../docs/SKILLS-INDEX.md)
- **استفاده در محیط agent:** کل پوشه اسکیل را به مسیر skills محیط مقصد کپی کنید.

- ساختار معمول یک اسکیل: `SKILL.md` + `routes/scenes/references` (بسته به نوع اسکیل).

حذف‌شده‌ها از آرشیو: `__pycache__` و `.DS_Store` (فقط کش؛ بدون اثر بر عملکرد).
