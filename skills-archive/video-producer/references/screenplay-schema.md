# اسکیمای کامل screenplay.json

این سند مرجع کامل ساخت فایل فیلمنامه است. فیلمنامه معیارِ همه فازهای بعدی است؛
دقت اینجا = کیفیت ویدیوی نهایی.

## ساختار پوشه پروژه

```
<project-dir>/
├── screenplay.json      ← تو می‌نویسی (تنها فایل ورودی لازم)
├── images/              ← فاز ۲ می‌سازد (scene_01.png ... + credits.png)
├── voice/               ← فاز ۳ می‌سازد (scene_01.wav ...)
├── music/               ← فاز ۴ می‌سازد (ambient.wav)
├── work/                ← فاز ۵ می‌سازد (کلیپ‌های میانی، subtitles.ass)
└── output/final.mp4     ← خروجی نهایی
```

## فیلدهای سطح بالا

| فیلد | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `project` | string | — | نام پروژه (اسم پوشه) |
| `title` | string | — | عنوان انگلیسی فیلم (روی پلیت عنوان + تیتراژ) |
| `title_fa` | string | — | عنوان فارسی (زیر عنوان انگلیسی روی پلیت عنوان) |
| `style_prompt` | string | — | **پیشوند ثابت همه visual_promptها** — یکدستی بصری |
| `voice` | string | `"jam"` | صدای TTS (jam برای مستند انگلیسی توصیه می‌شود) |
| `speed` | float | `0.95` | سرعت روایت (0.5–2.0؛ 0.95 ریتم مستندی می‌دهد) |
| `music.enabled` | bool | `true` | پد آمبیانت |
| `music.root_hz` | int | `110` | نت ریشه پد (A2=110 مرسوم؛ 98=G2 غمگین‌تر، 130.8=C3 روشن‌تر) |
| `music.volume_db` | int | `-23` | ولوم موسیقی نسبت به روایت |
| `scenes` | array | — | 4–16 صحنه |
| `credits` | array | — | نقش/نام تیتراژ پایانی |

## فیلدهای هر صحنه

| فیلد | الزامی | توضیح |
|---|---|---|
| `narration` | ✓ | جمله(های) روایت **انگلیسی** — ≤900 کاراکتر، 1–3 جمله |
| `subtitle` | ✓ | ترجمه فارسی همان روایت — وفادار به معنا، آزاد در واژگان |
| `visual_prompt` | ✓ | توصیف بصری سوژه صحنه (بدون تکرار style_prompt — خودش prepend می‌شود) |
| `motion` | ✓ | `zoom-in` \| `zoom-out` \| `pan-left` \| `pan-right` |
| `title_overlay` | ✗ | فقط برای صحنه اول `true` — عنوان فیلم fade-in می‌شود |

## قواعد نوشتاری روایت (درس‌گرفته از «هزاره‌های خاموش»)

1. **قلاب در ۵ ثانیه اول**: جمله اول باید کنجکاوی بسازد — یک پارادوکس، یک عدد شگفت، یک سؤال.
2. **جمله‌های کوتاه روایی**: 8–15 کلمه. صدای jam با جمله‌های کوتاه طبیعی‌تر است.
3. **قانون سه‌پرده**: صحنه‌های اول = قالب‌سازی (context)، میانه = توسعه با جزئیات ملموس،
   پایان = بستن احساسی (یک تصویر ذهنی ماندگار).
4. **اعداد و اسامی مشخص**: «thirty-four people» بهتر از «many people». جزئیات = اعتبار مستند.
5. **آخرین جمله = رزونانس**: مثل فیلم الگو که با «your living inside it» تمام می‌شود.
6. زیرنویس فارسی: نیم‌فاصله‌ها را درست بگذار (می‌کنیم، ویدیو...). لحن محاوره‌ی معتبر مستند.

## قواعد visual_prompt

- سوژه را **ملموس** توصیف کن: نور، جنس ماده، قاب دوربین، عمق میدان.
- برای پیوستگی کاراکتر/مکان در صحنه‌های متوالی، عناصر ثابت را در پرامپت تکرار کن
  (مثلاً «the same amber dusk light» در هر دو صحنه).
- از متن/لوگو/واترمارک در پرامپت بپرهیز (در style_prompt هم «no text» هست).
- حرکت دوربین را در visual_prompt ننویس — آن کار `motion` است.

## نکته همگامی

مدت هر صحنه به‌صورت خودکار = `0.6 + dur(narration) + 0.8` ثانیه.
پس **طول جمله روایت = ریتم صحنه**. جمله بلند بخواهی صحنه کش‌دارتر می‌شود؛
برای صحنه‌های پُر actionable، جمله را کوتاه نگه دار.

## تیتراژ (credits)

هر آیتم `{role, name}` یک خط از پلیت تیتراژ است (رنگ off-white روی زمینه تیره،
مثل فیلم الگو: `WRITTEN & DIRECTED BY • Claude Opus 5.5`).
نقش‌ها را با ابزارهای واقعیِ استفاده‌شده پر کن؛ صادقانه و بدون اغراق.
پلیت تیتراژ ~10 ثانیه با زوم آهسته در تدوین نشان داده می‌شود.
