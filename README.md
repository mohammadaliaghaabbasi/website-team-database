## 📋 این ریپو چیست؟

این مخزن پاسخ به این سوال است: «ساخت یک سایت کامل دقیقاً به چه تخصص‌هایی نیاز دارد؟» — پاسخ در پنج لایه:

1. **سیستم برنامه‌ریزی صفر تا صد** ([`WORKFLOW.md`](WORKFLOW.md) + ورد/PDF + شیت اکسل): نقشه اجرای هر پروژه طراحی سایت — ۶ فاز، ۱۹ مرحله؛ هر مرحله با ورودی، فعالیت، خروجی، مسئولان (۶۱ نقش)، ابزارها، معیار عبور و پرامپت آماده شروع وایب‌کدینگ. **این سند نقطه شروع هر پروژه جدید است.**
2. **دیتابیس ابزارها** (اکسل): ۱۸۳ ابزار متن‌باز در ۱۹ بخش، هرکدام با ریپوی گیت‌هاب، لینک، **ستاره واقعی** (واکشی مستقیم از github.com) و توضیح فارسی.
3. **شبیه‌ساز متخصصان** (ورد/PDF): کارت کامل ۶۱ نقش تخصصی — مأموریت، مهارت‌ها، پشته فناوری، **صفحات الهام و الگو**، پلتفرم تمرین، مسیر رشد و سوال مصاحبه.
4. **صفحات الهام** (`data/inspiration_data.json`): ۲۶۸ صفحه مرجع برای ۶۱ نقش — هر عضو تیم قبل از شروع کارش از گالری‌ها و مراجع تخصصی همان حوزه الگو می‌گیرد؛ شامل هر ۲۱ سایت راهنمای BUILD (نویسنده: Sanskaar Singh — @thesanskaarsingh، ترجمه فارسی) که به نقش‌های مرتبط اضافه شده‌اند.
5. **آرشیو اسکیل‌ها** (`skills-archive/`): هر ۸۰ اسکیل هوش مصنوعی این محیط — برای استفاده مجدد، توسعه و مرجع.

## 🚀 استفاده سریع

### 🎯 می‌خواهی سایتی طراحی کنی؟ (مهم‌ترین حالت)
1. [`WORKFLOW.md`](WORKFLOW.md) را باز کن — نقشه کامل ۱۹ مرحله از بریف تا بازاریابی.
2. پرامپت آماده مرحله ۱ را کپی کن و به دستیار هوش مصنوعی بده (خروجی: PRD).
3. مرحله‌به‌مرحله جلو برو: کارت متخصص همان مرحله + صفحات الهامش + معیار عبورش.
4. سند خروجی هر مرحله را در `docs/` پروژه‌ات بایگان کن — ورودی مرحله بعد است.

### فقط خروجی‌ها را می‌خواهی؟
به `deliverables/` برو:
- **برنامه‌ریزی صفر تا صد (ورد/PDF)** — نقشه اجرای هر پروژه
- **اکسل** برای جست‌وجوی ابزارها، مقایسه ستاره‌ها و شیت برنامه‌ریزی
- **ورد/PDF شبیه‌ساز** برای مطالعه کارت‌های متخصص و برنامه‌ریزی تیم/استخدام/یادگیری

### می‌خواهی توسعه اش بدهی؟ (گسترش)
```bash
# ۱) افزودن ریپوی جدید به دیتابیس: scripts/gh_collect.py → دیکشنری REPOS
# ۲) واکشی ستاره واقعی (از ریشه ریپو):
python3 scripts/gh_collect.py
# ۳) تغییر مراحل برنامه‌ریزی: scripts/build_workflow.py → لیست STAGES
# ۴) بازساخت همه خروجی‌ها:
python3 scripts/build_workflow.py
python3 scripts/build_xlsx.py
npm install docx && node scripts/build_docx.js && node scripts/build_workflow_docx.js
```
راهنمای کامل: [`docs/EXTENDING.md`](docs/EXTENDING.md)

### نصب پیش‌نیازها
- Python 3.9+ با `openpyxl` (`pip install openpyxl`)
- Node.js 18+ با پکیج `docx` (`npm install docx`) — فقط برای ورد
