## 📋 این ریپو چیست؟

این مخزن پاسخ به این سوال است: «ساخت یک سایت کامل دقیقاً به چه تخصص‌هایی نیاز دارد؟» — پاسخ در سه لایه:

1. **دیتابیس ابزارها** (اکسل): ۱۸۳ ابزار متن‌باز در ۱۹ بخش، هرکدام با ریپوی گیت‌هاب، لینک، **ستاره واقعی** (واکشی مستقیم از github.com) و توضیح فارسی.
2. **شبیه‌ساز متخصصان** (ورد/PDF): کارت کامل ۶۱ نقش تخصصی — مأموریت، مهارت‌ها، پشته فناوری، پلتفرم تمرین، مسیر رشد و سوال مصاحبه.
3. **آرشیو اسکیل‌ها** (`skills-archive/`): هر ۸۰ اسکیل هوش مصنوعی این محیط — برای استفاده مجدد، توسعه و مرجع.

```
website-team-database/

├── deliverables/                 ← خروجی‌های نهایی آماده استفاده
│   ├── دیتابیس-مهارت‌های-طراحی-سایت.xlsx
│   ├── شبیه‌ساز-متخصصان-تیم-طراحی-سایت.docx
│   └── شبیه‌ساز-متخصصان-تیم-طراحی-سایت.pdf
├── docs/                         ← مستندات تکمیلی
│   ├── EXTENDING.md             ← راهنمای گسترش دیتابیس (افزودن ابزار/متخصص)
│   ├── DATA-MODEL.md            ← ساختار فایل‌های JSON
│   └── SKILLS-INDEX.md          ← فهرست ۸۰ اسکیل آرشیوشده
└── skills-archive/               ← آرشیو کامل ۸۰ اسکیل (هرکدام با SKILL.md)
```

## 🚀 استفاده سریع

### فقط خروجی‌ها را می‌خواهی؟
به `deliverables/` برو:
- **اکسل** برای جست‌وجوی ابزارها و مقایسه ستاره‌ها
- **ورد/PDF** برای مطالعه کارت‌های متخصص و برنامه‌ریزی تیم/استخدام/یادگیری

### می‌خواهی توسعه اش بدهی؟ (گسترش)
```bash
# ۱) افزودن ریپوی جدید به دیتابیس: scripts/gh_collect.py → دیکشنری REPOS
# ۲) واکشی ستاره واقعی (از ریشه ریپو):
python3 scripts/gh_collect.py
# ۳) بازساخت اکسل و ورد:
python3 scripts/build_xlsx.py
npm install docx && node scripts/build_docx.js
```
راهنمای کامل: [`docs/EXTENDING.md`](docs/EXTENDING.md)

### نصب پیش‌نیازها
- Python 3.9+ با `openpyxl` (`pip install openpyxl`)
- Node.js 18+ با پکیج `docx` (`npm install docx`) — فقط برای ورد
