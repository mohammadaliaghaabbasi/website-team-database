# 📤 خروجی‌های نهایی

خروجی‌های آماده استفاده — با اسکریپت‌های `scripts/` تولید شده‌اند؛ دستی ویرایش نکنید.

| فایل | محتوا |
|---|---|
| `دیتابیس-مهارت‌های-طراحی-سایت.xlsx` | ۲۲ شیت: خلاصه (۳ ابزار برتر هر بخش) + ۱۹ بخش (۱۸۳ ابزار با ستاره واقعی) + ۸۲ پلتفرم تمرین + راهنما |
| `شبیه‌ساز-متخصصان-تیم-طراحی-سایت.docx` | ۶۱ کارت متخصص در ۱۹ مرحله: مأموریت، ۶ مهارت، پشته با ستاره واقعی، صفحات الهام و الگو، تمرین، مسیر رشد، سوال مصاحبه |
| `شبیه‌ساز-متخصصان-تیم-طراحی-سایت.pdf` | نسخه PDF همان سند |

سکشن «صفحات الهام و الگو» در هر کارت: ۴-۵ صفحه مرجع تخصصی که عضو تیم باید **قبل از شروع کار** مرور کند — از نمونه واقعی و الگوی آماده همان حوزه ایده بگیرد (ایده با الهام از پست «۲۱ سایت کاربردی برای ساخت سایت با AI» — farshad_frhni، تعمیم‌یافته به همه ۶۱ نقش با ۲۴۷ صفحه).

تاریخ ستاره‌ها: **2026-11-20** — برای تازه‌سازی: `python3 scripts/gh_collect.py` و بازتولید.
